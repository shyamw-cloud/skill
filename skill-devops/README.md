# DevOps Skill Pack

A Skill Forge-ready collection of DevOps and infrastructure skills for deployment, cloud, and operational reliability.

## Included Skills

- `deployment-planning`
- `ci-cd-review`
- `incident-response`
- `infra-audit`
- `cloud-cost-review`
- `system-health-check`

## Quick Start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m devops_skill --list
```
