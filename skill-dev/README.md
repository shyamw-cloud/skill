# Dev Skill Pack

A Skill Forge-ready collection of development skills for coding, architecture, testing, and repository automation.

## Included Skills

- `refactor`
- `frontend-design`
- `web-design-reviewer`
- `diagram-generator`
- `webapp-testing`
- `code-change-verification`
- `mcp-builder`
- `repo-contribution`

## Quick Start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m dev_skill --list
```
