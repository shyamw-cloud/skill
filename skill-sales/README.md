# Sales Skill Pack

A Smithery-ready collection of sales and revenue skills for lead prioritization, pipeline strategy, and forecasting.

## Included Skills

- `lead-prioritization`
- `sales-forecast`
- `proposal-generator`
- `pipeline-review`
- `renewal-risk-analyzer`
- `sales-enablement`

## Quick Start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m sales_skill --list
```
