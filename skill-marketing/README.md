# Marketing Skill Pack

A Skill Forge-ready collection of marketing and audience skills for campaigns, segmentation, content strategy, and customer engagement.

## Included Skills

- `campaign-planner`
- `content-strategy`
- `seo-audit`
- `audience-segmentation`
- `brand-positioning`
- `lead-nurture-planner`

## Quick Start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m marketing_skill --list
```
