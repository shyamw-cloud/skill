# Analytics Skill Pack

A Smithery-ready collection of analytics and insight skills for performance review, forecasting, anomaly detection, and executive reporting.

## Included Skills

- `dashboard-analysis`
- `trend-analysis`
- `anomaly-detector`
- `kpi-reporting`
- `executive-summary`
- `market-insight-generator`

## Quick Start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m analytics_skill --list
```
